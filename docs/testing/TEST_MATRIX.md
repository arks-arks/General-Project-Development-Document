# Test Matrix

> 用途：把“改了什么”映射为“至少要测什么”，并区分软件验证与真实环境验收。

## 测试等级

| 等级 | 定义 | 示例 | 不能证明 |
|---|---|---|---|
| L1 | 静态/编译 | lint、类型、语法、编译、UTF-8/BOM | 运行行为正确 |
| L2 | 自动测试 | 单元、组件、契约、回归 | 未覆盖输入与真实依赖 |
| L3 | 软件运行/集成 | UI、进程、服务、模拟器、隔离安装 | 真实设备/生产负载 |
| L4 | 真实环境/硬件 | 现场设备、真实网络、存储、负载、故障注入 | 未执行的工况 |

## 模块最低验证矩阵

| 修改范围 | L1 | L2 | L3 | L4 | 数据保护/回滚 |
|---|---|---|---|---|---|
| UI/布局 | 语法、样式检查 | 渲染逻辑测试 | 多分辨率与交互 | 目标设备 DPI | 截图与旧版对照 |
| API/协议 | schema/类型 | 契约和异常测试 | 双端联调 | 真实对端 | 兼容旧版本 |
| 数据库 | migration 检查 | 临时库测试 | 真实规模副本 | 受控生产迁移 | 备份与恢复演练 |
| 文件/存储 | 路径与权限检查 | 临时目录测试 | 空间不足/只读 | 真实介质 | 禁止误删数据 |
| 外部设备 | 编译/配置检查 | 模拟器/桩 | 软件到模拟器 | 真机与故障注入 | 安全态与人工复位 |
| 构建/更新 | 脚本语法 | validator | 隔离安装启动 | 目标机器 | 产物哈希和回滚 |
| 安全逻辑 | 静态分析 | 状态机回归 | 断线/重启/超时 | 真实负载和急停 | 默认安全态 |

## 真实环境验收要求

- 记录设备/系统版本、接线/网络、负载、测试前安全状态。
- 记录输入、持续时间、实际输出、异常日志和测试后安全状态。
- 用户口头反馈与自动采集证据分开标注。
- 未测量的时间、距离、电压、吞吐、温度或可靠性不得估算成验收结论。
